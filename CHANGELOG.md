# Changelog

All notable changes to this website will be documented in this file.

The format is inspired by Keep a Changelog, and this project follows a simple date-based release history.

## [2.0.0] - 2026-05-30

### Added
- New `Tic Tac Toe` game page at `tictactoe.html`.
- New `Type Speed Test` experience at `type speed test/index.html` with:
  - Multiple durations (30s, 60s, 120s)
  - WPM and accuracy tracking
  - Restart flow and keyboard-first interaction
- Homepage links for the new game pages.
- Sitemap entries for:
  - `tictactoe.html`
  - `type speed test/index.html`

### Changed
- `BUSIFY` page now includes a launch-date countdown and updated launch messaging.
- Shared interaction polish for accessibility and clarity:
  - Better keyboard focus visibility for links and controls
  - Theme toggle state now reflects active theme more clearly
- `Snake` game improvements including smoother rendering and visual polish.

### Fixed
- Removed stale sitemap reference to `pool.html`.
- Removed tracked macOS metadata file (`.DS_Store`) from version control.
